# AzHST Release Notes

## 2026-10-05 - v0.2.0

### Added/Refactoring/Deprecation

- Feat(presentations): make Professional Night the default PowerPoint theme
- Feat(projects): reopen saved visualizations and improve them through contextual follow-up requests
- Feat(presentations): generate PowerPoint reliably from content-rich visualizations
- Feat(exe): add portable mode, which keeps settings and project history with extracted application files
- Feat(ui): load a fresh set of sample questions on demand

### Fixed/Improvements

- Patch(visualizations): recover missing Azure icon labels from trusted catalog metadata

## 2026-10-02 - v0.1.0

### Added/Refactoring/Deprecation

- Feat(visualization): turn Azure questions into interactive visual explanations
- Feat(architecture): provide visual guidance for Azure service choices and cloud designs
- Feat(comparison): compare Azure services and trade-offs side by side
- Feat(presentations): export visual answers as editable PowerPoint decks
- Feat(preview): let users review results in the app or their preferred browser
- Feat(personalization): let users choose AI models and output themes
- Feat(storage): keep generated visualizations and presentations available locally
- Feat(platforms): make AzHST available across Windows, macOS, and Linux
