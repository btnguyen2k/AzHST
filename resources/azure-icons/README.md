# Azure architecture icons

These SVG files are used only inside AzHST-generated architecture diagrams,
training material, and technical documentation.

Source and current terms:
[Azure Icons - Azure Architecture Center](https://learn.microsoft.com/azure/architecture/icons/)

Microsoft permits copying, distributing, and displaying the icons for
architectural diagrams, training materials, or documentation. Microsoft
reserves all other rights.

AzHST follows the published usage guidelines:

- show the Microsoft product name close to its icon
- use icons only to illustrate Microsoft products and how products work together
- do not use the icons to represent AzHST or another product
- do not crop, flip, rotate, recolor, distort, or change the icon shape

Generated pages embed the original SVG bytes as base64 `data:` images. This
keeps each artifact standalone without modifying the icon artwork.
